# Color System - Nomma

Este sistema de cores foi projetado para transmitir confiança, tecnologia e sofisticação, com foco em acessibilidade e legibilidade tanto em Light quanto em Dark Mode.

## Paleta Principal

| Token | HEX | RGB | Uso |
| :--- | :--- | :--- | :--- |
| **Primary (Navy)** | `#0F172A` | `(15, 23, 42)` | Cor base da marca, fundos escuros. |
| **Primary Light** | `#3B82F6` | `(59, 130, 246)` | Elementos de destaque, botões, ícones ativos. |
| **Accent (Sky)** | `#0EA5E9` | `(14, 165, 233)` | Gráficos, indicadores de progresso, detalhes. |
| **Off-White** | `#F8FAFC` | `(248, 250, 252)` | Fundo em Light Mode, texto em Dark Mode. |

## UI Tokens

### Dark Mode (Default)
| Token | HEX | Uso |
| :--- | :--- | :--- |
| **Background** | `#020617` | Fundo principal da aplicação. |
| **Surface** | `#0F172A` | Cards, menus, áreas de conteúdo. |
| **Surface Alt** | `#1E293B` | Inputs, sub-elementos. |
| **Text Primary** | `#F8FAFC` | Títulos e corpo de texto principal. |
| **Text Secondary**| `#94A3B8` | Legendas e textos menos importantes. |
| **Border** | `#334155` | Divisores e bordas sutis. |

### Light Mode
| Token | HEX | Uso |
| :--- | :--- | :--- |
| **Background** | `#F8FAFC` | Fundo principal. |
| **Surface** | `#FFFFFF` | Cards e containers. |
| **Surface Alt** | `#F1F5F9` | Áreas de destaque neutro. |
| **Text Primary** | `#0F172A` | Texto principal. |
| **Text Secondary**| `#475569` | Textos de apoio. |
| **Border** | `#E2E8F0` | Divisores. |

### Estados e Categorias
| Token | HEX | Significado |
| :--- | :--- | :--- |
| **Success (Income)**| `#10B981` | Receitas, metas atingidas, positivo. |
| **Danger (Expense)**| `#EF4444` | Despesas, alertas críticos, negativo. |
| **Warning** | `#F59E0B` | Atenção, orçamentos próximos do limite. |
| **Investment** | `#8B5CF6` | Patrimônio, investimentos. |

## Acessibilidade
Todas as combinações de `Text Primary` sobre `Surface` e `Background` atendem ao padrão WCAG AA de contraste.
